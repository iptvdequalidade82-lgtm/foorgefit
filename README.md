OBJETIVO PRINCIPAL

Não quero uma inspiração genérica.

Quero uma reconstrução detalhada da experiência do site, analisando a página inteira antes de começar a implementação.

Observe cuidadosamente:

estrutura completa da página;

ordem das seções;

textos;

títulos;

subtítulos;

parágrafos;

menus;

botões;

CTAs;

links;

cards;

formulários;

rodapé;

cabeçalho;

navegação;

espaçamentos;

alinhamentos;

tamanhos relativos;

hierarquia tipográfica;

bordas;

sombras;

elementos decorativos;

animações;

efeitos de hover;

transições;

comportamento responsivo;

versão desktop;

versão tablet;

versão mobile.

A implementação deve começar somente depois de analisar visualmente toda a página de referência.

1. RECRIE A ESTRUTURA EXATA

Mapeie o site de cima para baixo.

Para cada seção encontrada no site de referência, crie uma seção equivalente no novo site.

Mantenha:

mesma ordem;

mesma quantidade aproximada de elementos;

mesma hierarquia;

mesma lógica de composição;

mesma distribuição entre texto e elementos visuais;

mesma posição relativa dos CTAs;

mesma lógica de navegação.

Não simplifique a página.

Não remova seções simplesmente porque parecem secundárias.

Se o site tiver uma seção pequena, banner, aviso, bloco intermediário, FAQ ou elemento no rodapé, reproduza sua função e posição.

2. TEXTOS E CONTEÚDO

Para o conteúdo textual que eu tenho autorização para reutilizar, preserve o conteúdo do site de referência.

Não resuma.

Não transforme textos longos em textos curtos.

Não substitua automaticamente títulos por versões "melhores".

Não invente copy.

Mantenha:

títulos;

subtítulos;

textos;

chamadas;

CTAs;

perguntas;

respostas;

labels;

textos dos botões;

textos auxiliares;

mensagens;

menus.

Caso algum texto não possa ser reutilizado ou não esteja disponível, marque claramente o local com:

[TEXT0 DE REFERÊNCIA]

e mantenha exatamente o mesmo espaço e hierarquia visual para que eu possa substituir posteriormente.

3. IMAGENS

NÃO copie, baixe ou reutilize automaticamente as fotografias do site de referência.

Em vez disso, preserve o espaço destinado à imagem.

Analise:

proporção;

tamanho;

posição;

enquadramento;

formato;

bordas;

raio dos cantos;

sobreposição;

máscara;

espaço ao redor;

relação entre imagem e texto.

Substitua as imagens por placeholders claramente identificados, por exemplo:

[IMAGEM HERO]

[IMAGEM SEÇÃO 2]

[IMAGEM CARD 1]

[IMAGEM DEPOIMENTO]

O placeholder deve ocupar aproximadamente o mesmo espaço visual que a imagem original.

IMPORTANTE:

Não reorganize a seção apenas porque a imagem original não está disponível.

A estrutura deve continuar exatamente igual, aguardando a substituição das imagens posteriormente.

4. CABEÇALHO E MENU

Reproduza detalhadamente o cabeçalho.

Analise:

altura;

logo;

posição da logo;

menu;

espaçamento entre links;

botão principal;

botão secundário;

comportamento ao rolar a página;

menu mobile;

menu hamburger;

efeitos de hover;

sticky header, caso exista.

O cabeçalho deve ter comportamento equivalente ao site de referência.

5. HERO / PRIMEIRA DOBRA

Reproduza a primeira dobra com máxima fidelidade.

Analise:

altura;

largura do conteúdo;

posição do título;

tamanho do título;

subtítulo;

CTA principal;

CTA secundário;

imagem;

elementos decorativos;

alinhamento;

espaços vazios;

background;

elementos sobrepostos.

O primeiro viewport deve transmitir a mesma composição visual do site de referência.

6. BOTÕES E CTAs

Reproduza todos os CTAs encontrados.

Não transforme todos os botões em um único botão genérico.

Preserve:

texto;

tamanho;

formato;

posição;

hierarquia;

estilo;

ícone;

espaçamento;

estado hover;

animação;

comportamento ao clicar.

Cada CTA deve possuir sua própria função correspondente.

Se o botão leva para outra seção, faça o scroll para a seção correta.

Se abre formulário, modal ou outra página, reproduza esse comportamento quando possível.

7. COMPONENTES

Identifique todos os componentes reutilizáveis do site.

Exemplos:

cards;

depoimentos;

FAQ;

tabelas;

listas;

badges;

números;

estatísticas;

formulários;

banners;

menus;

botões;

blocos de benefícios;

blocos de serviços;

blocos de preços.

Crie componentes organizados e reutilizáveis no código.

Não duplique código desnecessariamente.

8. TIPOGRAFIA

Analise visualmente a tipografia utilizada.

Reproduza:

família ou equivalente disponível;

peso;

tamanho;

line-height;

letter-spacing;

caixa alta/baixa;

hierarquia entre H1, H2, H3 e corpo;

largura máxima dos textos.

Se a fonte original não estiver disponível, escolha a alternativa mais próxima visualmente.

Não escolha uma fonte aleatória apenas por preferência.

9. CORES E IDENTIDADE VISUAL

Extraia visualmente a lógica de cores do site.

Reproduza:

background;

textos;

títulos;

botões;

bordas;

cards;

destaques;

elementos secundários;

gradientes;

estados de hover.

Organize as cores em variáveis/tokens para que possam ser alteradas facilmente depois.

10. ESPAÇAMENTO E GRID

Preste muita atenção aos espaços.

Não quero apenas "elementos parecidos".

Quero que a composição tenha proporções semelhantes.

Observe:

padding;

margin;

gap;

largura máxima;

grid;

colunas;

alinhamento vertical;

alinhamento horizontal;

distância entre título e subtítulo;

distância entre texto e CTA;

distância entre seções.

Evite colocar todos os elementos próximos uns dos outros.

Reproduza a sensação de espaço do site de referência.

11. RESPONSIVIDADE

O site precisa funcionar perfeitamente em:

desktop;

notebook;

tablet;

celular.

Não faça simplesmente uma versão desktop que "encolhe".

Analise como a referência reorganiza os elementos em telas menores.

Verifique:

quebra de linhas;

tamanho dos títulos;

colunas;

ordem dos elementos;

imagens;

botões;

menus;

espaçamentos;

cards;

formulários.

No mobile, mantenha a mesma lógica visual da referência.

12. ANIMAÇÕES E INTERAÇÕES

Identifique as interações existentes.

Quando houver:

fade;

slide;

hover;

accordion;

carrossel;

sticky;

scroll animation;

contador;

menu expansível;

modal;

transição;

implemente comportamento equivalente.

As animações devem ser suaves e profissionais.

Não adicione animações aleatórias que não existam na referência.

13. FOOTER

Reproduza o rodapé completo.

Observe:

quantidade de colunas;

links;

textos;

contatos;

redes sociais;

botões;

logo;

divisores;

informações legais;

copyright;

espaçamentos.

Não trate o footer como uma seção genérica.

14. FUNCIONALIDADE

Além da aparência, reproduza a lógica de interação da página.

Teste:

todos os botões;

todos os links;

menu;

FAQ;

formulários;

navegação interna;

scroll;

elementos interativos;

versão mobile.

Nenhum botão deve ser apenas decorativo se houver uma ação correspondente na referência.

15. IMPORTANTE — NÃO INVENTAR

Não faça alterações criativas sem necessidade.

Não:

adicionar seções que não existem;

remover seções existentes;

mudar a ordem;

criar novos CTAs;

alterar a hierarquia;

inventar textos;

mudar a estrutura;

transformar uma seção em outra;

simplificar componentes complexos.

Se houver alguma informação que não possa ser reproduzida, preserve o local, tamanho e estrutura e use um placeholder.

17. PRIORIDADE DE FIDELIDADE

Use esta ordem de prioridade:

1º — Estrutura

2º — Hierarquia visual

3º — Layout

4º — Espaçamentos

5º — Tipografia

6º — Cores

7º — Componentes

8º — Interações

9º — Responsividade

10º — Detalhes visuais

Não quero apenas um site "parecido".

Quero que alguém que conheça o site de referência reconheça imediatamente a mesma estrutura e experiência de navegação, respeitando os direitos de uso do conteúdo e da identidade visual.

18. IMPLEMENTAÇÃO

Construa tudo do zero no Lovable utilizando uma arquitetura limpa e organizada.

Antes de finalizar:

percorra a página inteira;

verifique todas as seções;

verifique todos os CTAs;

verifique todos os links;

verifique todos os placeholders;

verifique desktop;

verifique mobile;

corrija problemas de espaçamento;

corrija problemas de alinhamento;

garanta que não existam elementos quebrados.

Não finalize apenas porque a página está funcional.

Ela precisa estar visualmente refinada.

REGRA FINAL

A referência deve ser tratada como um blueprint completo da experiência.

Analise primeiro.

Mapeie depois.

Implemente por último.

Não comece criando uma versão genérica e depois tente aproximá-la da referência.

Quero que você construa a página já pensando na referência seção por seção, mantendo a mesma lógica estrutural, conteúdo autorizado, hierarquia, posicionamento e experiência.
